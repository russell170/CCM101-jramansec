# Cloud Provider Comparison

## AWS vs Microsoft Azure vs Google Cloud

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering compute, storage, databases, networking, security, analytics, artificial intelligence, and many other categories. Its large service portfolio makes it suitable for organizations with diverse cloud requirements.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

Microsoft Azure integrates tightly with the Microsoft ecosystem — Active Directory, Microsoft 365, Windows Server licensing (often via existing enterprise agreements), and .NET tooling. This makes migration and identity management smoother for Microsoft-heavy shops.

## 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud is widely recognized for its strengths in artificial intelligence, machine learning, and Kubernetes-related technologies. Google also developed Kubernetes, which contributes to its strong position in container orchestration.

## 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent categories of infrastructure services, including compute, storage, networking, and identity and access management. Although the service names differ, they provide similar fundamental capabilities for building cloud infrastructure.
