# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is **AWS** because it offers a wide range of cloud services for different types of workloads. During this activity, I learned that AWS provides services for computing, storage, databases, networking, security, and other cloud solutions. I also found it useful that AWS can support both small startups and large organizations.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Microsoft Azure, and Google Cloud Platform have many similarities because all three provide cloud computing services through the internet. They offer virtual machines, storage, databases, networking, identity management, and Kubernetes services. All three platforms also allow organizations to scale their resources based on their needs instead of relying only on physical servers.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when selecting a cloud platform because different organizations have different needs, budgets, technologies, and workloads. For example, a company using many Microsoft technologies may benefit more from Azure, while an AI research organization may prefer Google Cloud. The decision should consider factors such as cost, scalability, performance, security, compatibility, and available services.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I learned to analyze the client's requirements first and then match those requirements with appropriate cloud services. This helped me understand how cloud computing can solve real-world business problems.

My GitHub Cloud Computing Portfolio became more organized and informative after completing this mission. This activity also helped me practice documenting technical work using Markdown and maintaining a professional project history through Git and GitHub.
