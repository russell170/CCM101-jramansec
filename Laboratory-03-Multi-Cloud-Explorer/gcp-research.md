# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a public cloud platform that provides computing, storage, networking, databases, AI, machine learning, and other cloud services.

## Global Infrastructure

Google Cloud provides infrastructure through global regions and zones. Its current infrastructure spans multiple continents and is designed to support high availability, performance, and global applications.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources.

## Four Core Services
1. Compute Engine – Provides virtual machines for running workloads.
2. Cloud Storage – Provides object storage for files and data.
3. Google Kubernetes Engine (GKE) – Provides managed Kubernetes for containerized applications.
4. Cloud IAM – Controls identities, roles, and permissions for Google Cloud resources.

## Three Advantages
1. Strong AI and machine learning capabilities.
2. Powerful global networking infrastructure.
3. Strong support for Kubernetes and containerized applications.

## Typical Enterprise Use Cases

Google Cloud can be used by enterprises for:

- AI and machine learning
- Data analytics
- Containerized applications
- Web application hosting
- Big data processing
- Global applications
