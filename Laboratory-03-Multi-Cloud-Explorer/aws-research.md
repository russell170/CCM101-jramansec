# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a public cloud platform that provides computing, storage, networking, databases, security, and many other cloud services.

## Global Infrastructure

AWS organizes its infrastructure into geographic Regions and Availability Zones. Each Region contains multiple isolated Availability Zones, which help applications achieve high availability and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

## Four Core Services

1. Amazon EC2 – Provides virtual servers for running applications.
2. Amazon S3 – Provides object storage for files and data.
3. Amazon VPC – Provides an isolated virtual network for AWS resources.
4. AWS IAM – Controls user access, permissions, and authentication for AWS resources.

## Three Advantages
1. Wide range of cloud services.
2. Global infrastructure and scalability.
3. Flexible pay-as-you-go cloud resources.

## Typical Enterprise Use Cases

AWS can be used by enterprises for:

- Web and mobile application hosting
- Data storage and backup
- Business applications
- Database systems
- Data analytics and machine learning
