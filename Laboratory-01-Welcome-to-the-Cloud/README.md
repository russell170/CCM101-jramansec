\# Laboratory 01 – Welcome to the Cloud



\## Overview



This laboratory provides practical experience with a cloud-based

Ubuntu Linux environment.



The activity focuses on basic Linux administration, system

information gathering, file management, documentation, and

version control.



\## Objectives



\- Access an Ubuntu cloud environment.

\- Practice Linux terminal commands.

\- Create and manage a Linux user.

\- Configure sudo access.

\- Gather system information.

\- Organize laboratory files.

\- Document technical activities.

\- Upload the completed work to GitHub.



\## Environment



The Linux activities were performed using KillerCoda Ubuntu.



The Windows-side project organization and Git operations were

performed using PowerShell.



GitHub was used to store and manage the final laboratory files.



\## Main Activities



1\. Accessed the KillerCoda Ubuntu environment.

2\. Checked the Linux user and system environment.

3\. Created a Linux user account.

4\. Added the account to the sudo group.

5\. Collected operating system information.

6\. Collected CPU information.

7\. Collected memory information.

8\. Collected storage information.

9\. Created the laboratory documentation.

10\. Organized screenshots and evidence.

11\. Initialized a Git repository.

12\. Uploaded the project to GitHub.
