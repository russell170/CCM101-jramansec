\# Reflection



\## My Experience



This laboratory allowed me to experience working with a Linux

environment through the cloud. Using the terminal helped me

understand that many system administration tasks can be performed

without relying on a graphical interface.



\## What I Learned



I learned how to check the current user, navigate directories,

create users, assign sudo permissions, and gather system information.



I also learned how to organize laboratory documentation and use

GitHub to maintain a record of my work.



\## Challenges



The main challenge was remembering the correct Linux commands and

understanding the purpose of each command.



It was also important to carefully check command outputs because

the information shown by the system may differ between environments.



\## Solution



I addressed these challenges by executing each command carefully,

checking the output, and verifying the files after creating them.



\## Importance



The activity is useful because Linux and command-line tools are

important components of many cloud environments.



Learning these fundamentals gives me a foundation for more advanced

cloud computing activities.



\## Conclusion



Overall, the laboratory improved my understanding of Linux,

cloud environments, system information, file organization, and

GitHub. It also gave me practical experience that I can apply

to future laboratory activities.
